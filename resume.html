FlexLight is a web-based fully modular render engine that supports real time Monte-Carlo Pathtracing (using BVHs and importance sampling). The engine uses PBR metallic materials and several approximations grounded in physics to achieve realistic lighting, including caustic effects. It allows obj file imports and supports fully dynamic scenes. Built originally using javascript and WebGL2 and pivoted in 2024 to WebGPU and typescript.
